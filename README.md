# HyMod - Polish Language Translation dla Hytale 🇵🇱

Mod dodający opcję wyboru **języka polskiego (`Polski` / `pl-PL`)** oraz dedykowane polskie czcionki (**Fonts**) do gry **Hytale** (bez nadpisywania oryginalnego języka angielskiego `en-US`).

---

## 🎮 Cechy moda

- **Dodaje opcję języka polskiego (`Polski` / `pl-PL`) w ustawieniach gry**:
  - Nie zamienia języka angielskiego (`en-US`) – w każdej chwili możesz przełączać się w ustawieniach gry pomiędzy `English (US)` a `Polski`.
  - `client.lang` oraz `client_no_translation.lang` – pełne spolszczenie interfejsu klienta, menu, ustawień, ekwipunku i edytorów.
  - `server.lang` – spolszczenie nazw przedmiotów, bloków, mobów, komend i komunikatów serwerowych dla języka `pl-PL`.
- **Dedykowane czcionki z polskimi znakami** (ą, ć, ę, ł, ń, ó, ś, ź, ż):
  - *Lexend-Bold*, *NotoMono-Regular*, *NunitoSans-ExtraBold*, *NunitoSans-Medium* (wraz z atlasami glifów `.png`).

---

## 🚀 Jak zainstalować i włączyć język polski?

1. Skopiuj plik **`PolishLanguageTranslation.jar`** do folderu modów gry:
   - **Windows**: `%APPDATA%\Hytale\UserData\Mods\`
   - **Linux**: `~/.local/share/Hytale/UserData/Mods/`
2. Włącz mod **`PolishLanguageTranslation`** w ustawieniach świata (*World Settings -> Mods*) i wejdź na świat, aby mod dodał język polski do klienta.
3. W ustawieniach gry (**Settings -> General -> Language**) wybierz z listy język **Polski**.
