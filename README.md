# HyMod - Polish Language Translation dla Hytale 🇵🇱

Mod dodający opcję wyboru **języka polskiego (`Polski` / `pl-PL`)** oraz dedykowane polskie czcionki (**Fonts**) do gry **Hytale** (bez nadpisywania oryginalnego języka angielskiego `en-US`). Mod korzysta z tłumaczenia AI z powodu ilości rzeczy do przetłumaczenia ale na bieżąco jest ono sprawdzane i poprawiane.

---

## 🎮 Cechy moda

- **Dodaje opcję języka polskiego (`Polski` / `pl-PL`) w ustawieniach gry**:
  - Nie zamienia języka angielskiego (`en-US`) – w każdej chwili możesz przełączać się w ustawieniach gry pomiędzy `English (US)` a `Polski`.
  - `client.lang` oraz `client_no_translation.lang` – pełne spolszczenie interfejsu klienta, menu, ustawień, ekwipunku i edytorów.
- **Dedykowane czcionki z polskimi znakami** (ą, ć, ę, ł, ń, ó, ś, ź, ż):
  - *Lexend-Bold*, *NotoMono-Regular*, *NunitoSans-ExtraBold*, *NunitoSans-Medium* (wraz z atlasami glifów `.png`).

---

## 🚀 Jak zainstalować i włączyć język polski?

1. Skopiuj plik **`PolishLanguageTranslation.jar`** do folderu modów gry:
   - **Windows**: `%APPDATA%\Hytale\UserData\Mods\`
   - **Linux**: `~/.var/app/com.hypixel.HytaleLauncher/data/Hytale/UserData/Mods/`
2. Włącz mod **`PolishLanguageTranslation`** w ustawieniach świata (*World Settings -> Mods*) i wejdź na świat, aby mod dodał język polski do klienta.
3. W ustawieniach gry (**Settings -> General -> Language**) wybierz z listy język **Polski**.

# HyMod - Polish Language Translation for Hytale 🇵🇱

A mod that adds the **Polish language (`Polski` / `pl-PL`)** option and dedicated Polish fonts (**Fonts**) to **Hytale** (without overwriting the original English language `en-US`). Due to the large volume of content to translate, the mod uses AI-assisted translation, which is continuously reviewed and refined.

---

## 🎮 Mod Features

- **Adds the Polish language (`Polski` / `pl-PL`) option in game settings**:
  - Does not replace the English language (`en-US`) – you can switch between `English (US)` and `Polski` in the game settings at any time.
  - `client.lang` and `client_no_translation.lang` – full Polish translation of the client interface, menus, settings, inventory, and editors.
- **Dedicated fonts with Polish characters** (ą, ć, ę, ł, ń, ó, ś, ź, ż):
  - *Lexend-Bold*, *NotoMono-Regular*, *NunitoSans-ExtraBold*, *NunitoSans-Medium* (including `.png` glyph atlases).

---

## 🚀 How to Install and Enable the Polish Language?

1. Copy the **`PolishLanguageTranslation.jar`** file to the game's mods folder:
   - **Windows**: `%APPDATA%\Hytale\UserData\Mods\`
   - **Linux**: `~/.var/app/com.hypixel.HytaleLauncher/data/Hytale/UserData/Mods/`
2. Enable the **`PolishLanguageTranslation`** mod in the world settings (*World Settings -> Mods*) and join the world so the mod can add the Polish language to the client.
3. In the game settings (**Settings -> General -> Language**), select **Polski** from the list.
